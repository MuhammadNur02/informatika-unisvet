# Informatika Unisvet

Build a modern, elegant, and interactive website for Program Studi Pendidikan Informatika, Universitas Ivet Semarang. 

1. Design & Visual Aesthetic:

- Color Palette: Deep Navy Blue (primary), Clean White, Soft Slate Gray (backgrounds), and Warm Gold/Amber (accents).

- Style: Professional academic feel with modern Tech/SaaS web aesthetic (smooth rounded cards, glassmorphism headers, subtle drop shadows, clean grid layouts).

- Typography: Clean sans-serif fonts (e.g., Inter or Plus Jakarta Sans).

- Tone: Dynamic, progressive, warm, and inviting for prospective students.

2. Animations & Interactivity (Framer Motion / Lucide Icons):

- Smooth scrolling navigation.

- Header scroll effect: Sticky navbar with a blur background on scroll.

- Entrance animations: Subtle fade-in and slide-up animations for cards and sections as they enter the viewport.

- Hover effects: Interactive hover cards with subtle elevation, scale up, and border glow effects on feature boxes and CTA buttons.

- Animated statistics counters (e.g., total students, alumni, accredited status).

3. Structure & Main Components:

A. Header / Navigation Bar:

- Logo: Universitas Ivet Semarang logo + "Pendidikan Informatika" branding.

- Navigation Menu: Beranda, Profil (Visi Misi, Dosen/Staf), Akademik (Kurikulum, Akreditasi), Kemahasiswaan, Berita & Kegiatan, Kontak.

- CTA Button: "Pendaftaran PMB" (highlighted button with glow/hover effect).

B. Hero Section:

- High-impact headline: "Mencetak Pendidik & Ahli Teknologi Informasi Masa Depan".

- Subtitle: "Program Studi Pendidikan Informatika Universitas Ivet Semarang – Mengintegrasikan Keahlian Kependidikan dengan Teknologi Digital Terdepan."

- Primary Action Buttons: "Jelajahi Prodi" and "Daftar Sekarang".

- Visual: An interactive hero banner featuring an abstract tech grid pattern, high-quality illustrations or imagery of modern computing labs, and floating badge callouts (e.g., "Akreditasi Baik", "Kurikulum Berbasis Industry & EdTech").

C. Quick Stats Banner:

- Counter metrics for: Active Students, Alumni, Partner Companies/Schools, and Accreditation Status.

D. Mengapa Memilih Kami (Keunggulan Prodi):

- Grid layout with modern icons (Lucide React) featuring key selling points:

  1. Dual Capability: Pendidik IT Profesional & Software/Web Developer.

  2. Kurikulum Adaptif & Digital Learning.

  3. Fasilitas Laboratorium Komputer Modern.

  4. Jaringan Kemitraan Luas (DUDI & Sekolah Mitra).

E. Berita, Pengumuman & Agenda Terbaru:

- Tabbed or slider dynamic card section displaying news, campus events, and announcements with date badges, thumbnails, short excerpts, and a "Baca Selengkapnya" link.

F. Profil Pengajar & Fasilitas:

- Carousel/Grid showcasing faculty members (Dosen) with clean avatar cards, modern titles, and research interests.

- Gallery/Grid showcase of campus facilities (Lab IoT, Lab Multimedia, Smart Classroom).

G. Testimonial / Alumni Showcase:

- Interactive quote cards from successful alumni working as teachers, IT specialists, software engineers, or EdTech entrepreneurs.

H. Call to Action (CTA) Banner:

- A high-energy section inviting prospective students to enroll at Universitas Ivet Semarang with a direct link to the PMB portal.

I. Footer Section:

- Quick links, full address (Universitas Ivet, Jl. Pawiyatan Luhur IV No.18, Bendan Duwur, Kec. Gajahmungkur, Kota Semarang, Jawa Tengah), contact details (WhatsApp, Email, Telp), social media links, and a embedded Google Maps integration.

Please generate a fully responsive, pixel-perfect, clean TypeScript + React + Tailwind CSS code structure with smooth UI components.
